Chapters

How to review
  1. Each event is a moment where chemical bonds form or break. Its name says what happened.
  2. Select an event. The viewer jumps to it and highlights the atoms: green lines are bonds forming, red lines are bonds breaking. Use Play this event to watch it happen, and point at any atom to see which one it is.
  3. Check what changed, compare the model's suggestion, then Accept if the name is right or Reject if it isn't a real event or the name is wrong. You can type a better name first.
  4. Use Show to list only the events you still need to review.
